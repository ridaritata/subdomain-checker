# ⚡ Subdomains & Live Host Checker

A high-speed, asynchronous Python CLI tool designed for security researchers and penetration testers to quickly verify active subdomains and check their HTTP response status codes.

---

## 🚀 Features

* **Asynchronous Execution:** Powered by `asyncio` and `aiohttp` for maximum performance and fast scans.
* **Status Code Highlighting:** Uses colored output to distinguish between `200 OK`, redirection codes, and dropped connections.
* **Minimal Dependencies:** Lightweight, clean codebase ready for quick deployment.
